# Data organisation

- `raw/`: unchanged downloaded source snapshots.
- `interim/housing/legacy_docx/`: format-only DOCX copies of the four legacy DOC files. These are necessary Rmd inputs and are included permanently in this package.
- `processed/`: three analysis-ready reference datasets regenerated by the Rmd.
- `source_manifest.csv`: provenance for sources included in this repository. Exact monthly NBS URLs appear in the nested `source_urls.csv`.

The root README gives download and run instructions. DATA_DICTIONARY.md defines the output columns and units. Source snapshots are copied byte-for-byte; the provenance manifest is restricted to files included in this package.
